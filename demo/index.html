Advanced Combobox

A combobox for the shadcn registry. Simple, light, performatic, reusable — remote options, pagination and multi-select, all typed.

  • Single or multi selection with limits, clear button, error and required states
  • Remote options: lazy fetch, cancellation, input-driven search, shared cache, retries
  • Client or server pagination
  • Customizable menu items and trigger labels via props
  • Install: npx shadcn add "https://fernaandojr.github.io/advanced-combobox/r/combobox.json"
